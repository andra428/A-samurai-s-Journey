# A Samurai's Journey

A Samurai's Journey is a 2D platformer game developed in Java. The game follows the adventure of a samurai who must complete three levels, avoiding obstacles and defeating enemies along the way.

## Features

- Three levels with increasing difficulty
- Character movement and jumping mechanics
- Various obstacles, enemies and coins to collect

## Technologies & Libraries Used

- Java AWT for rendering and game mechanics
- Java Swing for window management
- BufferedImage for handling sprites and textures
- ImageIO for loading assets
- Rectangle for collision detection
- JPanel and JFrame for UI and game window

## Gameplay

- The player controls the samurai using keyboard input
- The goal is to reach the end of each level while avoiding traps and enemies and collecting coins
- Jumping, running, and attacking mechanics are implemented
- Different enemies provide different challenges

## Game Controls

- Arrow keys to move
- Spacebar to jump
- R key to attack
